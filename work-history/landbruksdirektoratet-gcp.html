Modernization and migration of central services from older Altinn, LDAP and Oracle based solutions to a modern platform on NAIS and Google Cloud Platform. The work covered integrations, data migration, identity management and new services, with significant technical ownership of migration strategy, performance improvements and integration design, while preserving compatibility with existing systems and avoiding unnecessary rewrites.

  • Took technical ownership of several modernization and migration initiatives across identity management, data integration and backend services.
  • Designed and implemented the migration from LDAP to Microsoft Entra ID.
  • Redesigned identity lookup to use synchronized snapshots and in-memory lookups instead of performing external LDAP calls during requests, removing identity-service latency from the request path.
  • Replaced legacy REST services and adapted authentication and user-management flows to the new identity architecture.
  • Resolved a blocking ETL and data-migration problem and designed the resulting solution using BigQuery, Oracle and PostgreSQL.
  • Built the ETL solution to replace direct database integrations and support the transition from Oracle-based systems to PostgreSQL on NAIS/GCP.
  • Designed a new data intake solution for actors such as Tine, replacing an Altinn/SFTP integration.
  • Used ID-porten for authentication and Google Cloud Storage for secure file and data intake.
  • Developed conversion scripts and upgraded close to one hundred JasperReports reports to the new data model.

Technology

Java, Spring Boot, GCP, NAIS, BigQuery, PostgreSQL, Oracle, Entra ID, LDAP, ID-porten, Altinn, REST, Google Cloud Storage, XML, Grafana and JSON.
