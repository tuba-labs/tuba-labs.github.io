Writers Workbench is a JetBrains IDE plugin for people who keep prose, documentation, notes, Markdown, comments, and planning files next to their code.

It started with a simple need: count words without leaving the editor. From there it grew into a small writing workbench for projects where text files are part of the actual work.

Word Count

  • Live word count for the active editor in the status bar.
  • Selection-aware counting when text is selected.
  • Project view action for counting words across selected files and folders.
  • Summary metrics for words, paragraphs, lines, characters, averages and file counts.
  • Per-file charts for the largest files by word count.
  • Skipped and unreadable file reporting, so the result is explainable.

AI Prompt Templates

Prompt templates are Markdown files in a project folder. They can be run against selected editor text or selected Project view files, then copied into whatever AI tool you prefer.

  • Default templates for prose improvement, scene diagnosis, continuity checks and chapter summaries.
  • Character sheets, timelines, world facts, revision goals and chapter meta-file update prompts.
  • Variables for selections, line numbers, file paths, folder paths and project name.
  • Template imports with {{import:Template Name}}.
  • Reusable user input variables for values that should be asked once and inserted many times.
  • Prompt-template context menu for inserting variables and choosing template imports from a dropdown.

Settings

The plugin has project settings for word-count limits, AI prompt limits, excluded file extensions and the Writers Workbench folder. The idea is to keep it useful for small notes and large manuscript projects without accidentally reading generated files, build outputs or large binaries.

It is built as a split-mode-ready IntelliJ plugin, with UI code separated from backend project logic. That matters for remote development, but the user-facing goal is simple: keep writing tools close to the text.
