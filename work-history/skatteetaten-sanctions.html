Development and modernization of Skatteetaten systems for automated follow-up and sanctions when businesses failed to report, or reported late. The systems supported rule-driven case handling, control, coercive fines and other sanctions across several business areas. The work included significant technical ownership of backend architecture, modernization, messaging patterns and testing practices across multiple subprojects.

  • Took technical ownership of backend architecture and modernization decisions across several subprojects.
  • Identified where asynchronous message-based processing was a better fit than existing Camel-based flows and drove the redesign of several services to use the platform-provided ActiveMQ service.
  • Designed and implemented a PostgreSQL-backed queueing mechanism for workflows where ActiveMQ was not a good fit.
  • Changed the testing approach from primarily frontend-driven testing to direct testing of backend functionality through REST APIs, improving isolation, repeatability and testability.
  • Designed and implemented rule-driven services, REST APIs, event-driven processing and integrations.
  • Modernized older systems from Java 8, Akka, Oracle, WebSphere and proprietary frameworks toward Java 17/21, Spring Boot, PostgreSQL, Docker and OpenShift/Kubernetes.
  • Established reusable development patterns and shared service components across multiple services.
  • Implemented integrations with Altinn and internal Skatteetaten registers.
  • Developed automated case-handling and complaint-handling workflows using message-based processing.

Technology

Java, Spring Boot, PostgreSQL, Oracle, OpenShift, Kubernetes, Docker, REST, ActiveMQ, Apache Camel, Altinn, JWT, XML, JSON, SOAP, Spring REST Docs, TDD and Testcontainers.
